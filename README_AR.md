# 🏥 نظام إدارة المستشفيات المتكامل

## 📋 نظرة عامة

نظام شامل لإدارة المستشفيات يشمل:
- ✅ **بحث المرضى** بالرقم القومي/الإقامة/جواز السفر
- 📋 **محاضر الاتصال** مع رفع المستندات
- 🏥 **الخدمات** مع أكواد المملكة + الكميات + الحساب التلقائي
- 📧 **نظام موافقات البريد الإلكتروني** للتأمين/الجمعيات (قبول/رفض عبر الرد على الإيميل)
- ✍️ **نظام التعهدات الخطية** (موقع/مرفوض)
- 💰 **إيصالات الدفع + أوامر التحصيل** (من المحصل إلى أمين الصندوق)
- 📄 **توليد PDF** مع شعار/ختم/توقيعات

---

## 🚀 التثبيت والإعداد

### 1. متطلبات النظام
```bash
- PHP >= 8.2
- MySQL >= 8.0
- Composer
- Node.js & NPM
```

### 2. تثبيت المشروع
```bash
# نسخ المشروع
git clone [repository-url]
cd hr-hospital-v2

# تثبيت المكتبات
composer install
npm install

# نسخ ملف البيئة
cp .env.example .env

# توليد مفتاح التطبيق
php artisan key:generate

# إنشاء رابط التخزين
php artisan storage:link
```

### 3. إعداد قاعدة البيانات
```bash
# تحديث ملف .env
DB_DATABASE=hr_app_hospital
DB_USERNAME=root
DB_PASSWORD=your_password

# إنشاء قاعدة البيانات
mysql -u root -p
CREATE DATABASE hr_app_hospital;
exit;

# تشغيل الـ Migrations
php artisan migrate

# تشغيل الـ Seeders (بيانات تجريبية شاملة)
php artisan db:seed
```

### 4. إعداد البريد الإلكتروني
```env
# في ملف .env
MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@hospital.sa
MAIL_FROM_NAME="Hospital System"
```

## 📊 البيانات المُحملة

الـ Seeders تضيف:

### ⚙️ إعدادات المستشفى
- اسم المستشفى والعنوان
- معلومات المدير (الاسم، المنصب)
- معلومات البنك (IBAN، رقم الحساب، SWIFT)
- الرقم الضريبي والسجل التجاري

### 🏢 الأقسام (18 قسم)
- الطوارئ، الجراحة، الأطفال، النساء والولادة
- الباطنية، القلبية، العظام، الأعصاب
- الأشعة، المختبر، الصيدلية، الأسنان
- الجلدية، الأنف والأذن، العيون، العلاج الطبيعي
- العناية المركزة، الدخول

### 🏥 الخدمات (35+ خدمة)
كل خدمة تحتوي على:
- **كود المملكة** (مثال: LAB-001، RAD-002، SUR-003)
- السعر الافتراضي
- القسم المسؤول
- دعم الجلسات المتعددة (للعلاج الطبيعي)

**أمثلة:**
- تحليل الدم الشامل (LAB-001) - 150 ريال
- أشعة مقطعية للدماغ (RAD-002) - 800 ريال
- استئصال الزائدة (SUR-001) - 5000 ريال
- جلسة علاج طبيعي (PHY-001) - 150 ريال × 10 جلسات

### 🏢 شركات التأمين (6 شركات)
- بوبا العربية
- التعاونية
- ميدغلف
- السعودية الهندية
- سلامة
- أليانز

**كل شركة لها:**
- بريد إلكتروني للموافقات
- رقم هاتف
- رقم ضريبي

### ❤️ الجمعيات الخيرية (6 جمعيات)
- جمعية البر بالرياض
- جمعية الملك سلمان
- جمعية الأمير سلطان
- جمعية البر بجدة
- جمعية مرضى الكلى
- جمعية رعاية مرضى السرطان

### 👥 المرضى (20 مريض)
- 14 مريض نقدي (Cash)
- 4 مرضى تأمين
- 2 مرضى جمعيات
- بيانات كاملة (الاسم، الهوية، العمر، الجنس، الكفيل)

## 🔄 سير العمل

### 1. البحث عن المريض
```
/patients/search
```
- البحث بالرقم القومي/الإقامة/جواز السفر
- إذا موجود: عرض التاريخ المرضي
- إذا غير موجود: تسجيل مريض جديد

### 2. إنشاء محضر اتصال
```
/contact-reports/create?patient_id=X
```
- عرض بيانات المريض
- رفع المستندات (عامة + ورقية ممسوحة)
- إمكانية التحويل لموظف متخصص

### 3. إنشاء فاتورة
```
/invoices/create?patient_id=X
```
- إضافة خدمات ديناميكية
- عرض أكواد المملكة
- حساب تلقائي للإجمالي
- **إذا كان المريض تأمين/جمعية:**
  - يتم إنشاء طلب موافقة تلقائياً
  - يُرسل إيميل للشركة/الجمعية

### 4. نظام الموافقات عبر البريد
**الإيميل المُرسل يحتوي على:**
- بيانات المريض الكاملة
- الخدمات المطلوبة مع الأكواد
- اسم المدير والموظف
- معلومات البنك (IBAN)
- المستندات المرفقة

**الرد على الموافقة:**
```
للقبول: أرسل رد بـ "APPROVE" أو "قبول"
للرفض: أرسل رد بـ "REJECT: السبب" أو "رفض: السبب"
```

### 5. التعهد الخطي
```
/written-commitments/create?patient_id=X
```
- إنشاء تعهد للمريض
- تحميل ملف التوقيع
- أو تسجيل الرفض مع السبب

### 6. إيصال الدفع
- تسجيل الدفع
- إنشاء إيصال تلقائي
- توليد أمر تحصيل من المحصل لأمين الصندوق

## 📧 نظام الموافقات المحسّن

### كيفية الرد على الإيميل:

**للموافقة:**
```
الموضوع: Re: Approval Request - APR-20260207-0001

قبول
```
أو
```
APPROVE
```

**للرفض:**
```
الموضوع: Re: Approval Request - APR-20260207-0001

رفض: الخدمة غير مغطاة في البوليصة
```
أو
```
REJECT: Service not covered in policy
```

### كل إيميل يحتوي على:
- ✅ اسم المدير ومنصبه
- ✅ اسم الموظف الذي أنشأ الطلب
- ✅ معلومات البنك الكاملة
- ✅ رقم مرجعي فريد (Token)
- ✅ المستندات الطبية مرفقة
- ✅ تفاصيل الخدمات مع أكواد المملكة
